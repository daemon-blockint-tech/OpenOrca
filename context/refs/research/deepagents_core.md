## Layout

- pnpm monorepo (`pnpm-workspace.yaml`): `libs/*`, `libs/providers/*`, `internal/*`, `evals/*`, `examples/**`. Root `package.json` is private; publishing via changesets.
- `libs/deepagents` — the core package, npm name `deepagents` (v1.13.0). Deps: only `fast-glob`, `micromatch`, `yaml`, `zod`; **`langchain` v1, `@langchain/core`, `@langchain/langgraph`, `@langchain/langgraph-checkpoint`, `@langchain/langgraph-sdk`, `langsmith` are peerDependencies**. Built with tsdown (ESM + CJS) with three entrypoints: `src/index.ts` (default), `src/browser.ts` (excludes Node-only APIs: `createSettings`, `listSkills`, `createAgentMemoryMiddleware`, `FilesystemBackend`, `LocalShellBackend`), `src/node.ts` (everything).
- `libs/deepagents/src/agent.ts` — `createDeepAgent`, the whole assembly pipeline (547 lines).
- `libs/deepagents/src/types.ts` — `CreateDeepAgentParams`, `DeepAgent`, `DeepAgentTypeConfig` + inference helpers.
- `libs/deepagents/src/middleware/` — all built-in middleware: `fs.ts` (filesystem tools + eviction, 2084 lines), `subagents.ts` (task tool), `summarization.ts`, `skills.ts`, `memory.ts` (AGENTS.md), `agent-memory.ts` (deprecated Node-fs variant), `async_subagents.ts` (remote Agent Protocol subagents), `completion_callback.ts`, `cache.ts`, `patch_tool_calls.ts`, `tool_exclusion.ts`, `utils.ts` (`mergeMiddlewareStack`).
- `libs/deepagents/src/backends/` — pluggable file storage: `protocol.ts` (+ `v1/protocol.ts` deprecated, `v2/protocol.ts` current), `state.ts` (`StateBackend`), `store.ts` (`StoreBackend`), `filesystem.ts` (`FilesystemBackend`), `composite.ts` (`CompositeBackend`, prefix routing), `sandbox.ts` (`BaseSandbox`), `local-shell.ts`, `langsmith.ts` (`LangSmithSandbox`), `context-hub.ts`, `utils.ts` (`adaptBackendProtocol`, v1→v2 adapters).
- `libs/deepagents/src/profiles/` — per-model "harness profiles": `harness/types.ts`, `registry.ts` (process-global registry on `globalThis` under `Symbol.for("deepagents.harness-profiles.v1")`), `create.ts`, `merge.ts`, `serialization.ts`, `builtins/` (anthropic-sonnet-4-6, anthropic-opus-4-7, anthropic-haiku-4-5, openai-codex).
- `libs/deepagents/src/permissions/` — filesystem permission rules (`types.ts`, `enforce.ts`).
- `libs/deepagents/src/skills/` — Node-fs skills loader utilities (`listSkills`, `parseSkillMetadata`).
- `libs/deepagents/src/stream.ts` — `DeepAgentRunStream` type overlay for `streamEvents({version:"v3"})`; `src/values.ts` — `filesValue` shared `ReducedValue`; `src/compat.ts` — deprecated legacy prompts (`BASE_AGENT_PROMPT` etc.) + `SystemPromptConfig`; `src/config.ts` — `createSettings`/`findProjectRoot`; `src/errors.ts` — `ConfigurationError`.
- `libs/providers/*` — sandbox/backend implementations: `@langchain/daytona` (`DaytonaSandbox extends BaseSandbox`), `@langchain/deno`, `@langchain/modal`, `@langchain/node-vfs` (`VfsBackend implements BackendProtocolV2`), `@langchain/quickjs`.
- `libs/acp` — `deepagents-acp`: Agent Client Protocol adapter (server, CLI, ACP filesystem backend). `libs/standard-tests` — `@langchain/sandbox-standard-tests`, conformance suite for sandbox backends. `evals/*`, `examples/*`, `internal/eval-harness` — not published.

## Core flow

`createDeepAgent(params)` in `src/agent.ts` is a **composer over langchain v1's `createAgent`** — there is no custom LangGraph graph. The loop itself (model call → tool node → repeat) is langchain's ReAct agent; deepagents contributes middleware, tools, prompt assembly, and typing. Assembly order:

1. **Collision check** — user tool names vs `BUILTIN_TOOL_NAMES` (`FILESYSTEM_TOOL_NAMES` = `ls, read_file, write_file, edit_file, delete, glob, grep, execute` from `middleware/fs.ts`; `ASYNC_TASK_TOOL_NAMES` = `start_async_task, check_async_task, update_async_task, cancel_async_task, list_async_tasks` from `middleware/async_subagents.ts`; plus `"task"`) → throws `ConfigurationError("TOOL_NAME_COLLISION")`.
2. **Harness profile resolution** — `resolveHarnessProfile` (`profiles/harness/registry.ts`): string model → exact `"provider:model"` key merged over bare `"provider"` key; model instance → `getModelProvider`/`getModelIdentifier` (`src/utils.ts`, sniffs `ConfigurableModel._defaultConfig` or class name `ChatAnthropic`/`ChatOpenAI`/`ChatGoogleGenerativeAI`). Falls back to `EMPTY_HARNESS_PROFILE`. Profile can rewrite tool descriptions, exclude tools/middleware, override the base system prompt, append a suffix, add extra middleware, and configure/disable the general-purpose subagent.
3. **Prompt assembly** — `normalizeSystemPrompt` + `assemblePromptParts` join `prefix / base(profile or user) / suffix / profile.systemPromptSuffix` with `\n\n` (string or `SystemMessage` content blocks).
4. **Provider-conditional cache middleware** — `isAnthropicModel` → langchain's `anthropicPromptCachingMiddleware` + `createCacheBreakpointMiddleware` (`middleware/cache.ts`, stamps `cache_control:{type:"ephemeral"}` on the last static system block, per-call gated on `request.model`); `isBedrockConverseModel` → `bedrockPromptCachingMiddleware`.
5. **Subagent normalization** — `subagents` array split by `isAsyncSubAgent` (discriminant: `graphId` field). Sync specs get a per-subagent default stack (`createFilesystemMiddleware`, `createSummarizationMiddleware`, `createPatchToolCallsMiddleware`, optional `createSkillsMiddleware` when the spec has `skills`), merged with the spec's own middleware and profile/cache/memory tails via `mergeMiddlewareStack`. `CompiledSubAgent` (`runnable` field) passes through untouched. A `general-purpose` subagent is auto-prepended (unless the profile disables it or the user supplies one by name), inheriting the main agent's model, tools, skills, and custom middleware.
6. **Main middleware stack** — core: `[skills?, FilesystemMiddleware, subAgentMiddleware, SummarizationMiddleware, PatchToolCallsMiddleware, asyncSubAgentMiddleware?]`; tail: `[profile.extraMiddleware, cacheMiddleware, MemoryMiddleware?, humanInTheLoopMiddleware(interruptOn)?]`. User `middleware` is merged via `mergeMiddlewareStack` (`middleware/utils.ts`): **same-`.name` custom entries replace built-ins in place; novel entries are inserted between core and tail**. Then profile `excludedMiddleware` names are filtered out, and `createToolExclusionMiddleware` is appended if the profile excludes tools (runs last so it catches middleware-injected tools).
7. **`createAgent({model, systemPrompt, stateSchema, tools, middleware, responseFormat, contextSchema, checkpointer, store, name, streamTransformers})`** then `.withConfig({recursionLimit: 10_000, metadata:{ls_integration:"deepagents"}})`, cast to `DeepAgent<DeepAgentTypeConfig<...>>` (pure type-level: return type merges built-in + user + flattened-subagent middleware states).

**Subagent runtime** (`middleware/subagents.ts`): `createSubAgentMiddleware` registers a single `task` tool (`createTaskTool`). Each declarative spec is pre-compiled to a `ReactAgent` via `createSubAgent(spec)` (which itself calls langchain's `createAgent`). On invocation the task tool grabs parent state with `getCurrentTaskInput()`, strips `EXCLUDED_STATE_KEYS` (`messages, todos, structuredResponse, skillsMetadata, memoryContents, _summarizationEvent, _summarizationSessionId`), seeds `messages` with just a `HumanMessage(description)` (handoff mode) or the parent's effective history + description (`fork` mode, via `getEffectiveMessages`), invokes the child graph, and returns a `Command` merging the child's file/state updates plus a `ToolMessage` carrying the last non-empty AI text or JSON-serialized `structuredResponse`. Dynamic per-call response formats: `config.configurable[SUBAGENT_RESPONSE_FORMAT_CONFIG_KEY]` triggers on-demand recompilation from the stored spec.

**Context management**: `middleware/fs.ts` evicts oversized tool results (`wrapToolCall`, default >20k tokens ≈ 4 chars/token) and oversized human messages (`beforeAgent`, >50k tokens) to backend files under `/large_tool_results/` and `/conversation_history/`, replacing them with a preview + read_file instructions. `middleware/summarization.ts` triggers on token thresholds (auto-computed from the model's `profile.maxInputTokens` — fraction 0.85 trigger / 0.10 keep — else fallback 170k tokens), offloads history to `/conversation_history/{session}.md`, and records a `_summarizationEvent{cutoffIndex, summaryMessage, filePath}` in state instead of rewriting messages; `getEffectiveMessages` reconstructs the working list per call.

## Public API

Everything below is exported from `libs/deepagents/src/index.ts` (`import { ... } from "deepagents"`).

- `createDeepAgent<TResponse, ContextSchema, TMiddleware, TSubagents, TTools, TStreamTransformers, TStateSchema>(params?: CreateDeepAgentParams) → DeepAgent<...>` — `src/agent.ts`. Full options (`src/types.ts` `CreateDeepAgentParams`):
  - `model?: BaseLanguageModel | string` — default `"anthropic:claude-sonnet-4-6"`.
  - `tools?`, `systemPrompt?: string | SystemMessage | SystemPromptConfig` (structured form deprecated), `stateSchema?` (LangGraph `StateSchema` or Zod object, merged with middleware state), `middleware?`, `subagents?: AnySubAgent[]` (= `SubAgent | CompiledSubAgent | ForkedSubAgent | AsyncSubAgent`), `responseFormat?`, `contextSchema?`, `checkpointer?: BaseCheckpointSaver | boolean`, `store?: BaseStore`, `backend?: AnyBackendProtocol | (({state, store}) => AnyBackendProtocol)` (default `new StateBackend(config)`), `interruptOn?: Record<string, boolean | InterruptOnConfig>` (HITL), `name?`, `memory?: string[]` (AGENTS.md paths), `skills?: string[]` (skill source dirs), `permissions?: FilesystemPermission[]`, `streamTransformers?`.
- `DeepAgent<TTypes>` (`src/types.ts`) — `extends ReactAgent<TTypes>` with a `"~deepAgentTypes"` brand and an overloaded `streamEvents(state, {version:"v3"}) → Promise<DeepAgentRunStream>` (typed projections: `run.messages`, `run.toolCalls`, `run.subagents` — a discriminated union over declared subagents — `run.middleware`, `run.values`, `run.output`, `run.extensions`). Stream types in `src/stream.ts`.
- Middleware factories (all return langchain `createMiddleware` results; `middleware/index.ts`): `createFilesystemMiddleware(options?)` (`fs.ts`; options: `backend, systemPrompt, customToolDescriptions, toolTokenLimitBeforeEvict=20000, humanMessageTokenLimitBeforeEvict=50000, permissions, tools` (FsToolName allowlist; `read_file` mandatory), `grepMaxCount=1000`), `createSubAgentMiddleware(SubAgentMiddlewareOptions)`, `createSummarizationMiddleware(options)` + `computeSummarizationDefaults`, `createPatchToolCallsMiddleware()` + `patchDanglingToolCalls()` (`patch_tool_calls.ts`, fixes tool_call/ToolMessage parity for strict providers like Gemini), `createMemoryMiddleware({backend, sources})` (`memory.ts`), `createAgentMemoryMiddleware` (deprecated), `createSkillsMiddleware({backend, sources})` (`skills.ts`), `createAsyncSubAgentMiddleware({asyncSubAgents})` + `isAsyncSubAgent`, `createCompletionCallbackMiddleware` (`completion_callback.ts`).
- Subagent helpers: `createSubAgent(spec, {responseFormat?})`, `GENERAL_PURPOSE_SUBAGENT`, `DEFAULT_SUBAGENT_PROMPT`, `SUBAGENT_RESPONSE_FORMAT_CONFIG_KEY` (`middleware/subagents.ts`).
- Backends (`backends/index.ts`): classes `StateBackend`, `StoreBackend`, `FilesystemBackend`, `CompositeBackend`, `ContextHubBackend`, `LocalShellBackend`, `LangSmithSandbox`, abstract `BaseSandbox`; guards/utils `isSandboxBackend`, `resolveBackend`, `adaptBackendProtocol`, `adaptSandboxProtocol`, `applyGrepMaxCount`; types `BackendProtocolV2`, `SandboxBackendProtocolV2`, `FileData`, result types.
- Profiles: `registerHarnessProfile(key, profileOrOptions)`, `getHarnessProfile(spec)`, `createHarnessProfile`, `serializeProfile`/`parseHarnessProfileConfig` (JSON round-trip, `harness/serialization.ts`), `EMPTY_HARNESS_PROFILE`, `REQUIRED_MIDDLEWARE_NAMES`.
- State: `filesValue` (`src/values.ts`) — reusable `ReducedValue` for a `files` channel in custom `StateSchema`s.
- Misc: `createSettings`/`findProjectRoot` (`src/config.ts`), `listSkills`/`parseSkillMetadata` (`skills/index.ts`), `ConfigurationError` (`src/errors.ts`), legacy prompts from `src/compat.ts`.

## Extension points

- **Custom middleware** — the primary hook. Write with langchain's `createMiddleware({name, stateSchema?, tools?, beforeAgent?, wrapModelCall?, wrapToolCall?})`; pass via `middleware: [...]`. **`.name` is load-bearing**: matching a built-in name (`"FilesystemMiddleware"`, `"subAgentMiddleware"`, `"SummarizationMiddleware"`, `"PatchToolCallsMiddleware"`, `"SkillsMiddleware"`, `"MemoryMiddleware"`…) replaces that built-in in place (`mergeMiddlewareStack`, `middleware/utils.ts`); a new name is appended between core and tail. Custom middleware also propagates into the general-purpose subagent's stack. Middleware `stateSchema` merges into agent state and into the return type.
- **Backends** — implement `BackendProtocolV2` (`backends/v2/protocol.ts`: `ls, read, readRaw, write, edit, grep, glob, delete?`) or `SandboxBackendProtocolV2` (adds `execute`, `id`). Easiest sandbox route: extend `BaseSandbox` (`backends/sandbox.ts`) and implement only `execute`/`uploadFiles`/`downloadFiles` — all file ops are derived from POSIX shell commands. v1 backends are auto-adapted by `resolveBackend`. `CompositeBackend` routes by path prefix (`routePrefixes`) to mix e.g. state + sandbox. Validate with `@langchain/sandbox-standard-tests`.
- **Harness profiles** — `registerHarnessProfile("provider" | "provider:model", {baseSystemPrompt?, systemPromptSuffix?, toolDescriptionOverrides?, excludedTools?, excludedMiddleware?, extraMiddleware?, generalPurposeSubagent?})`. Additive merges into a process-global registry; provider key is the base, model key overrides. `FilesystemMiddleware`/`SubAgentMiddleware` cannot be excluded (`REQUIRED_MIDDLEWARE_NAMES`).
- **Subagents** — declarative `SubAgent` (isolated `handoff`), `ForkedSubAgent` (`mode:"fork"`, inherits parent history + prompt, no own `systemPrompt`), `CompiledSubAgent` (any prebuilt `ReactAgent`/`Runnable`, including another `createDeepAgent` output), `AsyncSubAgent` (`graphId` + `url`, remote Agent Protocol server via `@langchain/langgraph-sdk`; adds the five `*_async_task` tools). Per-subagent `permissions` fully replace the parent's; per-subagent `skills`/`responseFormat`/`interruptOn` supported.
- **Skills** — drop directories containing `SKILL.md` (YAML frontmatter: `name` ≤64 chars, `description` ≤1024) under any backend path listed in `skills:`; progressive disclosure (metadata in system prompt, content read on demand via `read_file`); later sources shadow earlier by name.
- **Permissions** — `FilesystemPermission` (`permissions/types.ts`): `{operations: ("read"|"write")[], paths: absolute globs, mode?: "allow"|"deny"}`, first-match-wins, permissive default; enforced in `permissions/enforce.ts` inside every fs tool.
- **Streaming** — `streamTransformers` factories forwarded to `createAgent`, surfaced under `run.extensions`.

## Notes for integrators

- The state shape is not annotation-based; it's LangGraph v1 `StateSchema` + zod: `messages` (from `createAgent`), `files: Record<string, FileDataV1|FileDataV2>` with `fileDataReducer` (`middleware/fs.ts` — merge semantics, `null` deletes, safe for parallel subagents), `skillsMetadata`, `memoryContents`, private `_summarizationSessionId`/`_summarizationEvent`, and `tasks` for async subagents. `FilesystemStateSchema` is module-level singleton to avoid "Channel already exists" when many agents share a process; reuse `filesValue` if you declare `files` yourself.
- Model-agnosticism is three-layered: (1) model as string spec `"provider:model"` resolved by langchain's `initChatModel`, or any `BaseLanguageModel` instance; (2) provider sniffing (`src/utils.ts`) gates Anthropic/Bedrock cache middleware and is checked **per model call** in `cache.ts` so mid-run model fallback doesn't leak `cache_control` to other providers; (3) harness profiles tune prompts/tools per model. `patch_tool_calls.ts` papers over provider strictness differences.
- Persistence is standard LangGraph: pass `checkpointer`/`store` straight through; `StateBackend` writes files into checkpointed graph state via `filesUpdate` in `Command`s, `StoreBackend` into a `BaseStore`, `FilesystemBackend` to disk. Nothing else persists.
- `createFilesystemMiddleware` throws if `permissions` are combined with an execution-capable backend unless every permission path is scoped to a `CompositeBackend` route prefix (shell escape hatch would bypass glob rules).
- `recursionLimit` is hard-set to 10,000 via `.withConfig`; the returned agent is a langchain `ReactAgent`, so `invoke`/`stream`/LangGraph Platform integration all work unchanged. The `DeepAgent` cast is purely for type inference.
- Skills middleware caches loaded skills in a closure per middleware instance — one instance per agent, and skills reload only on cold state; account for that if skills change at runtime.
